# AgentHealth v0.17.0

Phase 19 adds Qdrant REST and Pinecone dense-vector data-plane REST health:
collection/index metadata, authentication, availability, latency and explicit
read-only top-1 vector queries. Vector services remain supporting dependencies;
agent, composite-agent and communication-path evidence stays separate.

## Changes and migration

- Add optional `vector_store` options to existing `vector-store` targets and
  both SDK schemas, strict Go/YAML validation and canonical diagnostics.
- Default checks are passive. Queries require explicit `functional` selection,
  `safe: true` and a finite nonzero dense vector matching metadata dimensions.
  Requests return at most one hit, disable data returns, never write and never retry.
- Register the adapter in check/doctor/serve; use config files rather than ping
  to supply provider and collection/index information.
- Add Qdrant 1.15.5 disposable CI coverage, response/transport regressions,
  documentation and examples; realign earlier phase status and future work.

Existing configuration, result v1, health states and exits are retained.
Placeholder vector-store targets without options remain configuration-valid,
but must add provider options for implemented checks. Existing HTTP-only vector
endpoint checks remain HTTP evidence; migrate explicitly when vector metadata
or query evidence is needed. No model/database behavior changes.

## Installation and synchronized artifacts

CLI downloads, DEB/RPM, Homebrew/Scoop manifests, Docker, Helm, OCI binary bundle,
Python and JavaScript SDKs all share v0.17.0. Verify checksums and GitHub signed
provenance before installation; see [installation](../installation.md) and
[distribution](../distribution.md). SDKs require the matching CLI.

```bash
docker run --rm ghcr.io/theagenthealth/agenthealth:v0.17.0 version
pip install agenthealth==0.17.0
npm install @theagenthealth/agenthealth@0.17.0
helm install agenthealth oci://ghcr.io/theagenthealth/charts/agenthealth --version 0.17.0
helm install agenthealth https://github.com/TheAgentHealth/agenthealth/releases/download/v0.17.0/agenthealth-0.17.0.tgz
oras pull ghcr.io/theagenthealth/agenthealth-binaries:v0.17.0
```

Release-source deployment files: [Kubernetes](https://github.com/TheAgentHealth/agenthealth/tree/v0.17.0/deploy/kubernetes),
[Helm](https://github.com/TheAgentHealth/agenthealth/tree/v0.17.0/deploy/helm/agenthealth),
[examples](https://github.com/TheAgentHealth/agenthealth/tree/v0.17.0/examples/kubernetes).
Chart 0.17.0 uses appVersion/image v0.17.0. Kubernetes runtime validation targets
1.32.2; broader Kubernetes versions remain unverified. Helm `.prov` signing is
not implemented; use GitHub keyless provenance rather than `helm --verify`.

## Limits

Controlled vector interoperability covers Qdrant 1.15.5; Pinecone API 2025-10
uses official-contract fixtures without live cloud-account verification.
Weaviate, Milvus, pgvector, OpenSearch, Elasticsearch, named/sparse vectors,
embedding generation and broad provider/version/cluster matrices remain planned.
An empty successful query proves execution, not relevance or corpus completeness.
Read charges may apply. No security audit or untrusted-tenant isolation claim.
See [vector guide](../vector-store-adapter.md),
[examples](../../examples/vector-check/README.md) and
[alignment review](../phase-19-alignment.md).

Publication is complete only after all synchronized release jobs and anonymous
artifact, registry and signed-provenance verification succeed.
