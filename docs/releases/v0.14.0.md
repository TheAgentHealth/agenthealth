# AgentHealth v0.14.0

Phase 16 introduces the Node.js JavaScript/TypeScript SDK:
`@theagenthealth/agenthealth@0.14.0`. It provides Promise-based checks,
JSON/YAML/object configuration, typed health/dependency/graph results, deadlines,
AbortSignal cancellation and sanitized typed errors around the reference CLI.
Node 22.14+ ESM and an explicitly installed verified CLI v0.14.0 are required.

```sh
npm install @theagenthealth/agenthealth@0.14.0
pip install agenthealth==0.14.0
```

See [installation](https://github.com/TheAgentHealth/agenthealth/blob/v0.14.0/docs/installation.md)
and the [SDK guide](https://github.com/TheAgentHealth/agenthealth/blob/v0.14.0/docs/javascript-sdk.md).
All implemented distributions share the v0.14.0 source tag: five CLI archives
and SBOMs, four Linux packages, channel manifests, Docker image, Helm chart,
OCI binary bundle, Python wheel/source archive and npm tarball. The npm package
is published via GitHub Actions OIDC using `publish.yml`, with provenance and
identical signed/checksummed GitHub download bytes. npm 0.0.0 is a historical
empty placeholder; use 0.14.0 for the SDK.

No AHS v1 or existing CLI behavior changes. Python SDK/CLI versions and chart
pins advance together; update both SDK and CLI when upgrading. Health exits 0–5
resolve to SDK reports; tool errors reject. Timeout units in Node are milliseconds.
Browser use, CommonJS require, automatic CLI downloads, Windows descendant-process
cleanup guarantees and broader framework interoperability are outside this release.
AHP remains experimental; OS-native signing/notarization remain planned.
