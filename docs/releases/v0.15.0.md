# AgentHealth v0.15.0

Phase 17 adds model/LLM health checks for OpenAI-compatible and Anthropic APIs.
Passive checks share one bounded model listing for reachability, authentication,
protocol and required model IDs. Rate limiting and overload produce stable
`DEGRADED` diagnostics. Explicit minimal inference uses a requested output token
limit and is never retried. Both SDKs accept the new canonical configuration.
Builds advance to Go 1.27.3 to fix GO-2026-6809 in crypto/x509.

Thanks to [Sharath K](https://github.com/sharath568) for the
[RFC](https://github.com/TheAgentHealth/agenthealth/issues/14) and
[original adapter](https://github.com/TheAgentHealth/agenthealth/pull/17).
The authored commit is preserved, with current-baseline integration, SDK parity,
response validation, transport/deadline/graph regressions and documentation added.

```sh
pip install agenthealth==0.15.0
npm install @theagenthealth/agenthealth@0.15.0
docker run --rm ghcr.io/theagenthealth/agenthealth:v0.15.0 version
helm upgrade --install agenthealth oci://ghcr.io/theagenthealth/charts/agenthealth \
  --version 0.15.0 --set-file config=./agenthealth.yaml
```

All implemented distributions share immutable source tag v0.15.0: five CLI
archives with five CycloneDX SBOMs, four Linux packages, two channel manifests,
Docker images, chart `agenthealth-0.15.0.tgz`, OCI binary bundle, Python wheel/sdist
and npm tarball. Download files from this Release and verify checksums and
GitHub attestations using the [installation guide](https://github.com/TheAgentHealth/agenthealth/blob/v0.15.0/docs/installation.md).
Registry identities:

- Docker: `ghcr.io/theagenthealth/agenthealth:v0.15.0` and configured Docker Hub mirror `theagenthealth/agenthealth:v0.15.0`.
- Helm: `oci://ghcr.io/theagenthealth/charts/agenthealth`, version `0.15.0`, `appVersion: v0.15.0`.
- OCI download bundle: `ghcr.io/theagenthealth/agenthealth-binaries:v0.15.0`, retrieved with an artifact client such as ORAS.
- Python: `agenthealth==0.15.0`; npm: `@theagenthealth/agenthealth@0.15.0`.

Deployment sources: [manifests](https://github.com/TheAgentHealth/agenthealth/tree/v0.15.0/deploy/kubernetes),
[chart](https://github.com/TheAgentHealth/agenthealth/tree/v0.15.0/deploy/helm/agenthealth),
[examples](https://github.com/TheAgentHealth/agenthealth/tree/v0.15.0/examples/kubernetes).
The synchronized release gate tests Kubernetes 1.32.2; existing compatibility CI
also exercises 1.31.9 and 1.33.1. Check the tagged-source CI results for this release.

No breaking AHS v1/result/exit-code changes. Existing configurations remain valid;
model options require v0.15.0 or a build containing Phase 17. Upgrade SDK and CLI
together; Python, npm, chart and image versions advance in lockstep.

Limits: model listing advertises availability, not successful inference or answer
quality. Functional checks may incur charges; token limits depend on server
enforcement, and excess usage can only be detected after a response reports it.
Hosted provider compatibility is not established by controlled fixtures. The
contributor reports Ollama 0.40 testing; Bedrock/Vertex signing, Azure-specific
authentication, streaming and embeddings remain planned. AHP remains experimental;
OS-native signing, notarization and full conformance remain future work.
