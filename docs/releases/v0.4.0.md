# AgentHealth v0.4.0 — Foundation stabilization

v0.4.0 completes foundation stabilization before direct/composite agent health.

## Changes

- Align MCP/A2A missing required capabilities and incompatible server protocols
  with AHS: these failures are UNHEALTHY, returning exit 2.
- Expose optional stable engine-owned diagnostic codes in JSON/YAML. Unknown
  adapter codes and raw errors stay suppressed; status determines exit codes.
- Add default A2A 1.0 JSON-RPC: supported-interface selection, A2A-Version,
  tenant routing, GetTask/SendMessage, proto-JSON messages and task states.
  Explicit A2A 0.3.0 compatibility remains available.
- Honor the configured stdio discovery deadline, including cold startup;
  timeouts no longer imply a legacy server. Pin a legacy version for servers
  that silently ignore unknown methods.
- Reuse MCP initialization, inventories and sessions/processes per target;
  share A2A cards and passive RPC evidence. Keep deadlines, active opt-in,
  no active retries, isolated credentials and bounded resource cleanup.
- Add official current/legacy Python SDK HTTP/stdio integration tests, a
  published matrix and nightly checks. Fix legacy SDK JSON-RPC error-data parsing.
- Enforce native Windows owner-only OAuth token ACLs and validate permissions
  on the opened file; older inherited-ACL token files must be recreated by login.
- Add reachable-vulnerability scanning and Linux/macOS/Windows runtime CI.
  Pin Actions by SHA; build releases with patched Go 1.27.1.
- Normalize archive ownership, modes, timestamps and gzip/ZIP headers. Publish
  five CycloneDX SBOMs alongside five archives and checksums, with GitHub keyless
  signed build-provenance and SBOM attestations.

## Migration

Unpinned A2A targets, including ping/doctor, now use protocol 1.0. Set
`a2a.protocol_version: '0.3.0'` in configuration for a legacy peer. There is no
silent protocol downgrade. Missing required capabilities previously returned
exit 1, and incompatible server versions exit 4; both now return exit 2.

The JSON/YAML wire envelope retains `spec_version: v1`. Consumers must tolerate
the optional check `code`, absent codes and identifiers they do not recognize.
Existing adapters need not implement the optional per-target cleanup interface.

## Installation and verification

Download your platform archive and matching SBOM from this release and verify
against `checksums.txt`. See [installation and attestation verification](../installation.md)
and the [official SDK matrix](../interoperability.md).

## Validation and limits

Go race tests/vet, schema/Go-output fixtures, deterministic archive regression
checks, documentation examples and both official SDK integration sets are tested.
Security scanning uses govulncheck with a patched release toolchain.

A2A support is JSON-RPC only. REST/gRPC, streaming, push execution, agent-card
signature verification and OAuth acquisition for A2A are outside this release.
The SDK interoperability suite runs on Linux and does not establish external
OAuth-provider or other-language SDK compatibility. OS-native code signing and
macOS notarization are not provided. Reproducible packaging is not a claim that
arbitrary toolchains yield identical binaries. Phase 7 agent health, gateway/router,
graph execution and AHP remain planned.
