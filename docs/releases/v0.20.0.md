# AgentHealth v0.20.0

Phase 22 adds redacted Prometheus text, JSON Lines, OTLP/HTTP JSON log and
versioned webhook payloads to health CLI output. Shared graph node evidence
exports once per explicit ID; incoming relationships and criticality remain
distinct. Configured identities, endpoints and diagnostic text are omitted.

## Compatibility and limitations

No configuration, canonical JSON/YAML, SDK, AHP or health exit-code migration is
required. Exports retain topology shape and timing and are not anonymization.
Aliases are snapshot-local, not stable identifiers across configuration changes.
Delivery uses explicit external relays; no automatic network requests, retries,
scrape server, gRPC or durable queue are added. Actual collector/provider
interoperability remains unverified. See [export mapping](../observability.md),
[delivery examples](../../examples/observability/README.md) and the
[all-phase impact review](../phase-22-alignment.md).

## Installation and synchronized distribution

All implemented distributions require the same immutable v0.20.0 source tag:
five CLI archives/SBOMs, four Linux packages, channel manifests, Docker,
Helm, OCI binary bundle, Python wheel/sdist and npm tarball. Verify checksums
and signed provenance using the [distribution guide](../distribution.md).

```bash
python3 scripts/install_ci_binary.py v0.20.0 ./agenthealth
./agenthealth check deployment.yaml --format prometheus
pip install agenthealth==0.20.0
npm install @theagenthealth/agenthealth@0.20.0
docker run --rm ghcr.io/theagenthealth/agenthealth:v0.20.0 version
helm install agenthealth oci://ghcr.io/theagenthealth/charts/agenthealth --version 0.20.0
oras pull ghcr.io/theagenthealth/agenthealth-binaries:v0.20.0
```

Matching Kubernetes manifests/examples and chart 0.20.0 pin CLI/image v0.20.0.
Historical chart/CLI tags remain unchanged. GPG Helm `.prov` files are not
provided; use keyless GitHub attestations. Synchronized publication and public installation checks passed; see the
[verification record](verification-v0.20.0.md) for the actual scope and digests.
