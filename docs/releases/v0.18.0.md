# AgentHealth v0.18.0

Phase 20 adds a supported optional LangGraph/FastAPI integration in the Python
SDK. Dedicated safe graphs expose the existing agent health resource; allowlisted
async callbacks perform selected peer exchanges. A consumer node returns complete
typed CLI health reports and preserves cancellation and tool failures.

## Compatibility and limitations

Existing configuration/result v1 and exit codes are unchanged. No CLI framework
adapter or automatic runtime discovery is introduced. Other framework products
remain planned. Callbacks are trusted application code and cancellation is
cooperative; configure authentication, ingress limits and process limits.
See the [guide](../framework-integrations.md), [alignment](../phase-20-alignment.md)
and [tests](../../examples/reference/python/test_runtime.py).

## Installation and synchronized distribution

All implemented formats share v0.18.0: five CLI archives and SBOMs, Linux DEB/RPM,
Homebrew/Scoop manifests, Docker, Helm chart, OCI binary bundle, PyPI and npm.
Verify signed provenance and checksums using the [distribution guide](../distribution.md).

```bash
pip install 'agenthealth[langgraph]==0.18.0'
npm install @theagenthealth/agenthealth@0.18.0
docker run --rm ghcr.io/theagenthealth/agenthealth:v0.18.0 version
helm install agenthealth oci://ghcr.io/theagenthealth/charts/agenthealth --version 0.18.0
oras pull ghcr.io/theagenthealth/agenthealth-binaries:v0.18.0
```

The Python consumer and Node SDK require the matching verified CLI. The Python
HTTP handler does not. Framework extras are not bundled into CLI images/charts.
No runtime certification or new tenant-isolation guarantee is claimed.
