# AgentHealth v0.1.0 — first CLI preview

AgentHealth now provides a CLI for HTTP/API health checks with dependency-aware results and automation exit codes.

- Commands: `ping`, `check`, `doctor`, `version`.
- Output: terminal, JSON, YAML.
- HTTP checks: DNS/TCP/TLS/HTTP diagnostics, passive HEAD status/header expectations, environment-referenced bearer authentication, latency thresholds, and bounded opt-in GET body matching.
- Core policies: strict YAML validation, independent dependencies, critical/optional aggregation, timeout/retry controls, secret redaction, verified TLS, and no redirect following.
- Downloads: Linux AMD64/ARM64, macOS AMD64/ARM64, Windows AMD64, and SHA-256 checksums. Downloaded binaries do not require Go.

## Install

Download your platform archive below, verify its hash against `checksums.txt`, and extract it. Run:

```bash
./agenthealth version
./agenthealth ping http https://example.com
```

See [installation instructions](https://github.com/TheAgentHealth/agenthealth/blob/v0.1.0/docs/installation.md) and [HTTP configuration](https://github.com/TheAgentHealth/agenthealth/blob/v0.1.0/docs/http-adapter.md).

## Preview limitations

This is an early, pre-1.0 preview. Configuration and interfaces may change. HTTP/API are the implemented adapters; MCP/A2A and other target types currently report unsupported adapters. Default HTTP readiness requires a 2xx HEAD response, while body matching requires explicit functional-check opt-in. Binaries are cross-compiled, with automated runtime smoke checks on Linux AMD64; other platforms need broader runtime validation. Binaries are unsigned; signing, notarization, and SBOM publication remain future work.
